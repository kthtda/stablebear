Mathematical glossary
=====================

Short explanations of mathematical terms used throughout the documentation.
Linked terms show a preview on hover or keyboard focus; follow a link to
read its entry here.

.. glossary::
   :sorted:

   basis of a vector space
      A collection of vectors such that every vector in the space can be
      written in exactly one way as a finite linear combination of them.
      For example, :math:`(1,0,0)`, :math:`(0,1,0)`, and :math:`(0,0,1)`
      form a basis of :math:`K^3`: the coefficients in the combination
      are simply the three coordinates. The number of basis vectors is
      the dimension of the vector space.

   dendrogram
      A hierarchy of nested clusters indexed by a scale. At each scale,
      the clusters form a partition of the observations; as the scale
      increases, clusters may merge but never split. It is commonly drawn
      as a tree whose leaves are observations and whose branch heights
      indicate when clusters merge.

   direct sum of vector spaces
      A way to combine vector spaces while keeping their contributions
      independent. A vector in :math:`V \oplus W` is a pair :math:`(v,w)`,
      with :math:`v\in V` and :math:`w\in W`; addition and scalar
      multiplication act on each coordinate separately. For example,
      :math:`K^2\oplus K^3` is isomorphic to :math:`K^5`. For an infinite
      collection of spaces, only finitely many coordinates of each vector
      may be nonzero.

   freely generated vector space
      Think of a set :math:`S` as an alphabet. Just as letters are building
      blocks for words, the elements of :math:`S` supply the building
      blocks for vectors. Here we combine them using addition and scalar
      multiplication. Unlike letters in a word, their order in a sum does
      not matter, and repeated letters combine: for example,
      :math:`e_a+e_b+e_a=2e_a+e_b`.

      "Free" means that we impose no extra identifications beyond the
      rules of a vector space. Distinct letters give independent vectors:
      we do not, for example, declare :math:`e_c=e_a+e_b`.

      A vector space freely generated by a set :math:`S` has one basis
      vector :math:`e_s` for each element :math:`s\in S`. Its vectors are
      finite linear combinations of these basis vectors, with coefficients
      in a field :math:`K`, and each such expression is unique. For example,
      a set with three elements generates a copy of :math:`K^3`, with basis
      :math:`e_1,e_2,e_3`. Taking :math:`K=\mathbb{R}`, one vector is

      :math:`v = 2e_1 - 3e_2 + 0e_3`.

      Its coefficients are :math:`(2,-3,0)`: no different choice of
      coefficients gives the same vector. If the basis is infinite,
      each vector still uses only finitely many nonzero coefficients.
      No relations between the basis vectors are imposed.

   injective map
      A map is injective (or one-to-one) if distinct elements of its source
      have distinct images. Equivalently, :math:`f(x)=f(y)` implies
      :math:`x=y`. Each element of the target has at most one preimage;
      some target elements may have none. For example,
      :math:`f:K\to K^2`, :math:`f(a)=(a,0)`, is injective, but is not
      surjective because it never reaches a pair with a nonzero second
      coordinate.

   isomorphism
      A map that preserves the relevant mathematical structure and has an
      inverse that also preserves it. Objects related by an isomorphism
      have the same structure, though their elements may be represented
      differently. For vector spaces, an isomorphism is an invertible
      linear map. For example, :math:`(a,b)\mapsto(b,a)` is an isomorphism
      from :math:`K^2` to itself.

   kernel of a linear map
      The vectors that a linear map sends to zero. For
      :math:`f:V\to W`, the kernel is
      :math:`\ker f=\{v\in V\mid f(v)=0\}` and is a vector subspace of
      :math:`V`. For example, the kernel of :math:`f(a,b)=a+b` consists
      of all pairs :math:`(a,-a)`. A linear map is :term:`injective <injective map>`
      exactly when its kernel contains only the zero vector.

   preimage
      For a map :math:`f:X\to Y`, a preimage of an element :math:`y\in Y`
      is an element :math:`x\in X` such that :math:`f(x)=y`. There may be
      no such element, one, or several. For example, under
      :math:`f:\mathbb{R}\to\mathbb{R}`, :math:`f(x)=x^2`, both
      :math:`2` and :math:`-2` are preimages of :math:`4`.

      The notation :math:`f^{-1}(\{y\})` denotes the set of all preimages
      of :math:`y`; it does not require :math:`f` to have an inverse
      function. More generally, the preimage of a subset :math:`B\subseteq Y`
      is :math:`f^{-1}(B)=\{x\in X\mid f(x)\in B\}`.

   simplicial complex
      An abstract simplicial complex is a collection of finite nonempty
      sets, called simplices, that contains every nonempty subset of each
      simplex. The elements of these sets are called vertices. A simplex
      with :math:`k+1` vertices has dimension :math:`k`: a singleton is a
      vertex, a pair is an edge, and a triple is a filled triangle.
      Larger sets describe higher-dimensional analogues: four vertices
      form a filled tetrahedron, and so on.

      For example, including :math:`\{a,b,c\}` requires including its
      three edges and three vertices. The three edges can also occur
      without the filled triangle, giving just its boundary. "Abstract"
      means the complex records which vertices form simplices; no
      coordinates or embedding in Euclidean space are required. Some
      conventions also include the empty set as a simplex.

   surjective map
      A map is surjective (or onto) if every element of its target is the
      image of at least one element of its source. Several source elements
      may have the same image. For example,
      :math:`f:K^2\to K`, :math:`f(a,b)=a+b`, is surjective because every
      :math:`c\in K` is the image of :math:`(c,0)`.
